# راه‌اندازی آسان موبایل

در صفحه کاربر، اتصال اصلی IKEv2 است و بالاتر از روش‌های دیگر قرار دارد. Xray، ‏Netlify و Happ فقط در بخش بسته «روش جایگزین اتصال» نمایش داده می‌شوند. نوع دستگاه به‌صورت پیشنهادی انتخاب می‌شود و کاربر می‌تواند آن را تغییر دهد.

## آیفون و اندروید با Happ

۱. از دکمه فروشگاه رسمی، برنامه را نصب کنید؛ برای اندروید لینک APK رسمی هم موجود است.
۲. به صفحه کاربر برگردید و «افزودن اشتراک به Happ» را بزنید. باز شدن برنامه را تأیید کنید.
۳. اتصال مستقیم یا Netlify را انتخاب کنید، اتصال را بزنید و مجوز VPN سیستم را تأیید کنید.

دکمه از پیوند `happ://add/` برای تحویل ساب به برنامه استفاده می‌کند. نصب برنامه و تأیید سیستم همچنان با کاربر است. صفحه، برنامه‌ای را خودکار باز نمی‌کند و لینک خصوصی را برای سرویس تبدیل لینک نمی‌فرستد. اگر پیوند در مرورگر باز نشد، لینک ساب را کپی و داخل برنامه وارد کنید. نتیجه روی دستگاه و نسخه برنامه کاربر باید بررسی شود.

## روش جایگزین IKEv2

- آیفون: صفحه را در Safari باز کنید، پروفایل را دانلود و Allow را تأیید کنید. سپس Settings ← Profile Downloaded ← Install را انجام دهید. نصب از وب، بدون تأیید تنظیمات انجام نمی‌شود.
- اندروید: strongSwan را نصب کنید و فایل آماده را با برنامه باز و Import را تأیید کنید. اگر مرورگر فایل را به برنامه تحویل نداد، از Import داخل برنامه استفاده کنید.

پروفایل‌های فعلی نام کاربری، رمز و گواهی موردنیاز را در خود دارند؛ نیازی به تایپ دوباره این مشخصات نیست.
