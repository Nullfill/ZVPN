# راهنمای تکمیلی WARP

WARP همراه نصب اصلی و ارتقای پنل نصب می‌شود. در نصب تازه، مسیر آن تا زمان فعال‌سازی مدیر خاموش می‌ماند. در بازیابی و میگریشن، انتخاب‌های قبلی مدیر حفظ می‌شوند. اگر دانلود بسته Cloudflare ناموفق باشد، نصب پنل و VPN ادامه پیدا می‌کند و خطای WARP اعلام می‌شود؛ برای تلاش دوباره:

```bash
sudo bash /opt/zvpn-panel/app/ops/install-warp.sh
```

در تنظیمات پنل، دکمه روشن/خاموش فوراً ثبت و اعمال می‌شود؛ برای تغییر فهرست سایت‌ها و کاربران باید «ذخیره و اعمال تنظیمات» را بزنید. تغییر مسیر مربوط به اتصال‌های جدید است؛ برای نتیجه روشن، مرورگر یا برنامه را کامل ببندید و دوباره باز کنید.

مجموعه آماده Gemini شامل ورود و تأیید امنیتی گوگل هم هست. دامنه `www.google.com` برای صفحه CAPTCHA لازم است؛ بنابراین Google Search روی همین دامنه نیز مشمول می‌شود. سایت‌های مستثنا بر فهرست مشمول اولویت دارند. فهرست‌های سفارشی در ارتقا خودسرانه تغییر نمی‌کنند؛ دکمه افزودن مجموعه Gemini برای به‌روزکردن آن‌ها در دسترس است.

گوگل ممکن است روی IP مشترک WARP هم خطای ترافیک غیرعادی نشان دهد. یکسان‌بودن مسیر Gemini و صفحه تأیید، مشکل عبور از دو مسیر متفاوت را برطرف می‌کند اما رفع همه محدودیت‌های گوگل را تضمین نمی‌کند. IP نمایش‌داده‌شده در پنل مربوط به آخرین آزمایش اتصال است.

در IKEv2، گزینه سازگاری HTTP/3 ارتباط UDP/443 کاربران مشمول را می‌بندد تا مرورگر به TCP برگردد؛ این روی HTTP/3 سایت‌های دیگر همان کاربران هم اثر دارد. در Xray فقط دامنه‌های مشمول اعمال می‌شود. تشخیص دامنه با SNI است و بدون رمزگشایی محتوای TLS انجام می‌شود؛ ECH یا برنامه‌ای که نام مقصد را پنهان کند ممکن است قابل تفکیک نباشد.

آمار WARP از زمان فعال‌سازی ثبت می‌شود، payload عبوری را نشان می‌دهد و دوباره از سهمیه کاربر کم نمی‌شود. در قطع ناگهانی، آخرین بازه نمونه‌برداری ممکن است ثبت نشود. تنظیمات، ثبت‌نام دستگاه و آمار در بکاپ کامل تلگرام و GitHub قرار دارند.

منابع: [راهنمای رسمی Cloudflare](https://developers.cloudflare.com/warp-client/warp-modes/) · [راهنمای خطای ترافیک غیرعادی گوگل](https://support.google.com/websearch/answer/86640?hl=en)

برای برنامه Antigravity، دکمه «افزودن مجموعه Antigravity و API گوگل» را بزنید و تنظیمات را ذخیره کنید. این مجموعه APIهای برنامه، ورود گوگل و دامنه تنظیمات `antigravity-unleash.goog` را شامل می‌شود. اگر قبلاً `googleapis.com` در فهرست بوده، APIهای زیرمجموعه آن از قبل مشمول‌اند؛ اضافه‌کردن دوباره نام API به‌تنهایی درمان خطای کشور نیست. اتصال‌های باز برنامه با تغییر فهرست جابه‌جا نمی‌شوند؛ پس از اعمال، برنامه را کامل ببندید و دوباره باز کنید. پاسخ موفق وب‌سایت Gemini نیز به‌تنهایی دسترسی API آنتی‌گرویتی را ثابت نمی‌کند.
