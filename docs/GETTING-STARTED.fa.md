# راه‌اندازی ZVPN

## نصب روی سرور جدید

روی یک سرور Ubuntu یا Debian با دسترسی root اجرا کنید:

```bash
git clone https://github.com/Nullfill/ZVPN.git /tmp/zvpn-release
cd /tmp/zvpn-release
sudo bash install.sh
```

هنگام نصب، دامنه و مشخصات مدیر را وارد کنید. دامنه باید به IP این سرور اشاره کند. پنل، IKEv2، Xray و WARP نصب می‌شوند. در نصب تازه، WARP را هر زمان خواستید از «تنظیمات ← مسیر WARP» روشن کنید و سایت‌ها و کاربران را انتخاب کنید.

## بروزرسانی پنل فعلی

روی سروری که پنل نصب است اجرا کنید:

```bash
cd /opt/zvpn-panel/app
sudo bash upgrade.sh
```

از نصب دوباره یا دستور بازیابی برای بروزرسانی استفاده نکنید.

## انتقال به سرور جدید

این دستور را روی **سرور فعلی** اجرا کنید:

```bash
curl -fsSL https://raw.githubusercontent.com/Nullfill/ZVPN/main/ops/migrate-server.sh -o /tmp/migrate.sh && sudo bash /tmp/migrate.sh
```

آدرس و مشخصات ورود سرور جدید را وارد کنید. ابزار، یک کپی از کاربران، مصرف ثبت‌شده، تنظیمات، گواهی‌ها و WARP می‌گیرد و روی مقصد بازیابی می‌کند. بعد از آماده‌شدن مقصد، IP دامنه را تغییر دهید. اتصال‌های فعال باید دوباره وصل شوند.

در نسخه فعلی، مصرف و تغییراتی که بعد از زمان تهیه کپی روی مبدا ایجاد شوند، همگام‌سازی نهایی ندارند. تا پیش از بررسی مقصد، سرور قبلی را حذف نکنید.

## بازیابی وقتی سرور قبلی در دسترس نیست

از آخرین بکاپ کامل تلگرام یا مخزن خصوصی GitHub استفاده کنید. اطلاعات تا زمان همان بکاپ برمی‌گردند. بازیابی کامل، اطلاعات مقصد را جایگزین می‌کند؛ آن را برای بروزرسانی اجرا نکنید.
